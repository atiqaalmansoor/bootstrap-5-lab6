# Bootstrap 5 - Tourist Places of Pakistan

## Project Description
This project demonstrates the use of Bootstrap 5 to create a colorful and responsive table featuring four famous tourist places of Pakistan.

## Features
- Bootstrap 5.3.3 integration using CDN
- Colorful table rows
- Images with thumbnail styling
- Table borders and hover effects
- Short descriptions of tourist places

## Technologies Used
- HTML5
- Bootstrap 5.3.3
- CSS

## Tourist Places
1. Mohenjo-Daro
2. Faisal Mosque
3. Badshahi Mosque
4. Mazar-e-Quaid
